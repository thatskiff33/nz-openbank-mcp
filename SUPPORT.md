# Support

- **Questions and ideas:** [GitHub Discussions](https://github.com/thatskiff33/nz-openbank-mcp/discussions).
- **Bugs:** [open an issue](https://github.com/thatskiff33/nz-openbank-mcp/issues/new/choose) with the bug template.
- **Security problems:** report privately as described in [SECURITY.md](https://github.com/thatskiff33/nz-openbank-mcp/blob/main/SECURITY.md). Do not open a public issue.
- **Akahu accounts, tokens or bank connections:** contact [Akahu](https://www.akahu.nz/contact). This project cannot see or change your Akahu account.

Never paste tokens, account numbers or transaction data into an issue or discussion.
